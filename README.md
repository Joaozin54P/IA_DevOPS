## 📌 Sobre o repositório

Este repositório reúne exercícios, atividades e projetos desenvolvidos ao longo da disciplina de **Inteligência Artificial e DevOps**.

O objetivo é explorar conceitos de programação, automação, análise e processamento de dados, além de compreender como ferramentas e práticas de desenvolvimento podem ser aplicadas na construção de soluções tecnológicas.

As atividades são desenvolvidas principalmente em Python, utilizando conceitos de lógica de programação e tomada de decisão automatizada.

## 🎯 Objetivos de aprendizagem

- Desenvolver soluções utilizando Python.
- Aplicar conceitos de lógica e programação.
- Explorar técnicas de processamento e análise de dados.
- Compreender fundamentos de Inteligência Artificial.
- Conhecer ferramentas e práticas relacionadas a DevOps.
- Desenvolver projetos práticos para solucionar problemas do cotidiano.

## 📂 Projetos e atividades

### 🌡️ Análise de Temperatura e Recomendação de Roupas

Aplicação desenvolvida em Python que coleta informações de temperatura de uma cidade durante vários dias, processa os dados e gera recomendações de roupas de acordo com as condições climáticas.

**Funcionalidades:**
- Coleta de temperaturas ao longo de vários dias.
- Processamento e interpretação dos dados.
- Classificação das condições climáticas.
- Recomendações automatizadas de roupas para diferentes temperaturas.

**Conceitos aplicados:**
- Lógica de programação.
- Estruturas condicionais.
- Processamento de dados.
- Tomada de decisão automatizada.

**Tecnologia:** Python.
